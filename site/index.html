Autres briques du projet (à lancer en local)

  • Backend FastAPIAPI REST + WebSocket, base SQLite, migrations, tests. Le client s'y branche avec VITE_API_URL.
  • Analyse et modèlesSimulation d'équipage, pipeline scikit-learn / XGBoost, tableau de bord Streamlit.
  • Simulation radio MQTTTrames avec CRC, perte de paquets, délai Terre-Lune, accusés de réception.
  • Serveur embarqué SANS GuardianRègles d'alerte, file de synchronisation prioritaire, chiffrement des données génétiques.

Prototype de recherche, pas un dispositif médical. Toutes les données sont simulées. Sur ce site, SANS Guardian est un instantané en lecture seule enregistré depuis le vrai serveur : les actions d'écriture (séances, journal, voix) demandent le serveur en local. Les instructions sont dans le README.
